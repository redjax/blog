# Jot

[Jot](https://github.com/badlogic/jot) is a Markdown editor with inline comment threads. It's useful as a review tool when having someone proofread Markdown, or for working on documents collaboratively.

The Jot instance in this repository does **not** directly interface with the files in this repository. The idea is to copy/paste the raw Markdown, edit it in Jot, then copy/paste the finished product back to a document here.
